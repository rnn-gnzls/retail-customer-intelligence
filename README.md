# Retail Customer Intelligence

A data analytics and business intelligence project focused on analyzing retail transaction data to uncover sales trends, customer behavior, purchasing patterns, product performance, and customer retention opportunities.

> **Status:** In Progress — Data cleaning, customer analytics, PostgreSQL database integration, advanced SQL analysis, and analytical views are complete. Power BI dashboard development is in progress.

---

## Project Overview

**Retail Customer Intelligence** is an end-to-end analytics project designed to transform raw retail transaction data into actionable business insights.

The project combines Python for data preparation and feature engineering, PostgreSQL for structured data storage and advanced SQL analysis, and Microsoft Power BI for interactive business intelligence and visualization.

The analysis focuses on both **business performance** and **customer intelligence**, allowing the project to answer questions such as:

- How is revenue changing over time?
- Which products and markets generate the most revenue?
- Which customers contribute the most business value?
- What proportion of customers are repeat customers?
- Which customer segments are most valuable?
- How concentrated is revenue among high-value customers?
- Do customers return after their first purchase?
- Which purchasing periods generate the highest activity?

**Tech Stack:** Python · Pandas · PostgreSQL · SQL · Microsoft Power BI · DAX · Power Query

**Core Focus:** Data Analytics · Business Intelligence · Customer Analytics · RFM Analysis · Cohort Analysis · Customer Segmentation · Sales Analysis · Revenue Analysis · Product Analytics · Retention Analysis · SQL Analytics · Data Cleaning · Data Modeling · Data Visualization

**Dataset:** Online Retail (https://www.kaggle.com/datasets/abhishekrp1517/online-retail-transactions-dataset)
